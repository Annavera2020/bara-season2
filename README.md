Бара. Сезон 2 — интерактивный курс медитаций

Интерактивное веб-приложение по мотивам книги «Новые медитации Бары» — второй сезон медитативного курса про капибару Бара. Шесть уроков, каждый со своей историей, практикой дня, аудио-гидом и вопросами для рефлексии.

Живая версия: https://annavera2020.github.io/bara-season2/

О проекте

Проект переносит книгу в интерактивный формат: пользователь листает уроки, отмечает выполненные практики, слушает аудио-гид и отвечает на вопросы вечера прямо в браузере. Прогресс сохраняется локально (localStorage), так что можно вернуться к курсу в любой момент.

Функциональность





11 экранов: обложка с оглавлением, пролог, 6 уроков, итог сезона, финальная практика, эпилог



Прогресс-трекер с отметками пройденных уроков (кнопка ☰)



Блокировка перехода к следующему уроку, пока не отмечена практика дня



Плеер для аудио-гида (аудиофайлы подключаются отдельно, см. ниже)



Текстовые поля для ответов на вопросы вечера с автосохранением



Адаптивная вёрстка: мобильный вид (карточка) и десктопный вид (двухколоночный)



Поддержка светлой/тёмной темы устройства



Технологии

Один самодостаточный HTML-файл: HTML + CSS + vanilla JavaScript, без сборки и зависимостей. Иллюстрации встроены как base64. Шрифты — Google Fonts (Newsreader, Karla, IBM Plex Mono).

Как добавить аудио-гиды

Плеер каждого урока ищет файл audio/urok-<номер>.mp3 (например, audio/urok-8.mp3 для урока 8). Просто положи mp3-файлы с такими именами в папку audio/ — плеер заработает без правок кода.

Запуск локально

Файл index.html можно открыть прямо в браузере — сервер не требуется.
